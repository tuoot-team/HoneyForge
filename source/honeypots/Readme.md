# Ханипоты

**Ответственный:** @SoulProtocol  
**Стек:** Python; тонкий агент; Docker/изоляция

Эмуляторы **параметризуются профилем** из конструктора (не хардкод одного сценария).

| Уровень | Суть |
|---------|------|
| `low/` | Порты/баннеры из профиля → скан/коннект |
| `mid/` | fake-SSH / fake-HTTP: баннеры и креды из профиля → запросы |
| `high/` | Bonus: sandbox ОС |

**Сделать:** агент pull'ит профиль, применяет (reload без переустановки); буфер и досылка; скрытность; Low + Medium; стык с agent API. Bonus: High, honeytokens, анти-фингерпринт, jitter.
