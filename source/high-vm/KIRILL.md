# Сообщение Кириллу (можно скопировать)

Кирилл, готовим приёмку High (6b). Скинь VM из VirtualBox так:

1. Предпочтительно один файл **OVA** (или `.vbox` + диск `.vdi`/`.vmdk`).
2. Рядом текст по полям из `source/high-vm/manifests/TEMPLATE.md`: ОС, vCPU/RAM/диск, сеть, порты (RDP и т.д.), логины для входа, версия VirtualBox, есть ли snapshot «clean», что уже сделано по антидетекту, известные ограничения (привязка к хосту и т.п.).
3. Пароли - не в открытый чат репо, отдельным каналом.
4. Если есть sha256 образа - тоже пришли.

Мы кладём артефакт в `source/high-vm/inbox/`, гоняем smoke на стенде, потом `vm-image-upload` в центр и профиль `emulation` (рантайм на ловушке - VirtualBox / VBoxManage). Полный антидетект «под все гипервизоры» не обещаем - идём от твоего образа.
