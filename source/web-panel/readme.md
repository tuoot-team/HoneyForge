# Web UI

**Ответственный:** @propastin  
**Стек:** HTML/CSS/JS (+ лёгкий фреймворк), Chart.js, SSE

Панель для LAN с доступом извне. Пароль в `.env`. Только клиент Control API.

**Конструктор (UI):** мастер/форма профиля - уровень → сервисы/порты → баннеры → креды → logging/mask → save; затем bind к ловушке. Тексты UI в отдельном файле.

**Также:** login; pairing (код/QR); dashboard; realtime-лента; графики; **презентация** (акцент на конструктор + демо-петлю). Один ops-dashboard.
